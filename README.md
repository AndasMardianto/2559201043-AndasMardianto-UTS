# Senja Coffee

Website profil usaha kedai kopi untuk proyek UTS Pemrograman Web Dasar.

## Struktur folder

```text
senja-coffee/
├── index.html
├── tentang.html
├── katalog.html
├── kontak.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── img/
└── README.md
```

## Cara menjalankan
1. Ekstrak folder proyek.
2. Buka folder `senja-coffee` di Visual Studio Code.
3. Jalankan `index.html` melalui browser (disarankan memakai ekstensi Live Server).
4. Pastikan koneksi internet tersedia untuk Google Fonts, foto Unsplash, dan peta Google Maps.

## Halaman dan fitur
- **Beranda:** hero, ringkasan usaha, dan tiga menu unggulan.
- **Tentang:** cerita usaha, nilai, dan tiga anggota tim contoh.
- **Katalog:** delapan item menu dengan gambar, deskripsi, harga, pencarian, dan filter kategori.
- **Kontak:** alamat contoh, media sosial, embed peta, tabel jam operasional, dan form HTML5.
- Navigasi responsif/hamburger, efek hover, animasi CSS, dan layout Flexbox/Grid.

## Data yang wajib disesuaikan
Konten usaha, alamat, jam operasional, akun media sosial, email, nama tim, menu, dan harga di dalam HTML masih berupa contoh. Ganti dengan informasi usaha nyata yang dipilih untuk tugas. Foto berasal dari URL Unsplash dan Google Fonts digunakan untuk tipografi.

## Catatan formulir
Form kontak saat ini memeriksa input di browser dan menampilkan konfirmasi demo. Form belum mengirim pesan ke email/server karena proyek ini bersifat statis. Untuk penggunaan nyata, hubungkan ke backend atau layanan formulir.

## Teknologi
HTML5 semantik, CSS3 eksternal, dan JavaScript vanilla. Tidak menggunakan framework CSS maupun library JavaScript.
